## 3. Notable papers & what people are discussing (X / community)

### Papers (submitted ~Sep 17; arXiv)

- **How Do Agent Harnesses Create Value? Planning Information and Release Control in Stateful LLM Agents (Sep 17).** Fixed task-specific plans beat length-matched “sham” policy text by **+7.17 pp** success (gains on harder tasks). A cheap read-only terminal verifier rejects **61%** of invalid Retail episodes while withholding **17%** of correct ones for **&lt;$0.01**/episode. At high liability for false accepts, verifier alone captures most of the full stack’s benefit. Founder takeaway: invest in plan quality + cheap release control before another model swap.  
  Source: [arXiv:2609.20474](https://arxiv.org/abs/2609.20474)

- **UnifiedPlayers: Enhance Tool-Integrated Reasoning in Agentic RL (Sep 17).** Cooperative Planning / Execution / Evaluation players with role-specific GRPO rewards; +**≥3.5%** math and **≥3.9%** general reasoning vs strongest prior baseline; learned verifier **84.2%** adversarial detection; **2.03×** higher reward variance than self-consistency. Path for self-improving tool agents without static verifiers.  
  Source: [arXiv:2609.20089](https://arxiv.org/abs/2609.20089)

- **An Architecture for Long-Horizon Agents: Levels, Ticks and Cascaded Intelligence (Sep 17).** Harness thesis: continual operation before continual learning — hierarchical time-scale levels, clocked ticks, escalate to stronger models only after failed review. Ten-day campaign reproduced a published RL result with ~daily human attend; knowledge written early shaped later behavior without weight updates.  
  Source: [arXiv:2609.19519](https://arxiv.org/abs/2609.19519)

## 4. Hot topics & trends founders should know

1. **RSI is now a measurable product/policy surface.** Expect investors, enterprises, and eventually regulators to ask for AL-style automation levels, agent-monitor coverage, and safety-compute share — start logging analogous internal metrics even if you’re not a frontier lab.  
2. **Pre-release evaluation windows are moving from op-ed → institutional proposal.** Hassabis’s 30-day voluntary → mandatory pass-to-deploy framework is the clearest public blueprint this week; plan release calendars with buffer if you touch “frontier-class” thresholds later.  
3. **CoT monitorability is a first-class risk.** Shah’s essay + Astra’s reported drop in monitorability = don’t assume “show thinking” remains a free safety feature; design agent audits that survive opaque reasoning.  
4. **Harness & verifier ROI &gt; model beauty contests (again).** Sep 17 papers quantify planning content and cheap release control; pair with yesterday’s Dream-RSI / EchoPath / RIR / SFT-vs-RL theme.  
5. **Enterprise distribution is shifting to “context where the agent already lives.”** AIforce/Claudeforce pattern (CRM/permissions into Claude/Slack) is the B2B packaging trend — MCP + zero-retention + prebuilt skills.
