Confirmed as a claim, unreviewed.** The paper "A 2^o(n) Time Algorithm for 3-SAT" is credited to Claude. The Lean 4 project (Mathlib v4.33.1) uses only the three standard axioms. The paper also says the bound does not beat brute force unless n > 10^10,000. Jelani Nelson posted it to Hexagon. ([GitHub anthropics/formal-math](https://github.com/anthropics/formal-math/tree/main/eth) · [Hexagon](https://hexagonmath.org/2610.00577v1) · [Popular AI](https://www.popularai.org/p/openai-exponential-time-hypothesis-proof))

## What to read / what to watch

1. **Anthropic, "How AI agents shape experts' judgment calls"** (Oct 27, institutional research, top pick). The RCT design is the lesson: hidden coin-flip leans on four analytical decisions (yield per hectare vs per operating cost, diff-in-diff vs adjusted comparison, enrolled farms vs all members, equal vs size weighting) in a farming-co-op task where each choice moves the estimate by several points against a 3–4% threshold. From the four leans alone, a model predicted 82% of the final recommendations. Proposed fixes: measure deferral, design agents that argue both sides or ask first, and have institutions decide which calls need independent judgment. ([Anthropic](https://www.anthropic.com/research/agents-judgment-calls) · [paper PDF](https://www-cdn.anthropic.com/519c17a5d23a794e8b6d50a854048d0b61e0d73a.pdf))
2. **Latent Space, "How Anthropic ships the #1 LLM in the World safely: Separating the Brain from the Hands"** (Oct 27, podcast, standing radar). swyx opens the IPO series with S-1 context (revenue per employee $6.6M vs $1.4M a year ago). Anthropic's platform leads then cover several practical points. Claude Managed Agents runs the harness on a durable server and spawns sandboxes ("hands") only to execute. Credentials sit in a separate vault and are injected by an egress proxy, so the agent only ever sees placeholders. Egress allow-lists come by default. The Messages API was ported from a Python monolith to **Rust** with shadow traffic, cutting CPU by ~40–50% and time to first token by ~10–20%. They also call **CPU and sandbox capacity** as scarce as GPUs. ([Latent Space](https://lspace.beehiiv.com/podcast/s/latent_space_the_ai_engineer_podcast/how_anthropic_ships_the_1_llm_in_the_world_safely_separating_the_brain_from_the_hands))
3. **Lucas Firmo, "How I run AI agents on production code"** (Oct 8, essay, **New creator**; first time in these briefs, via Layer 2). He treats an agent as "a process that forgets": task state lives in files, not context, and timers drive merges outside any conversation. Each task gets its own git worktree, and an agent must claim a ticket before touching it. "A rule in a markdown file is a request. A hook is a decision." A second model from a different family must sign off on the exact commit before a PR can open, and proof (screenshot, real-run output or a red/green pair) is a merge requirement. Agents can't edit their own safety checks. The result: a Swift 6 strict-concurrency migration in 10 days. ([Bits with Lucas](https://www.bitswithlucas.com/blog/ai-agents-on-production-code/))
4. **Simon Willison, "The October inflection point for vibe game development"** (Oct 28, essay, standing radar). He argues October 2026 is to vibe-coded games what November 2025 was to coding agents. His evidence includes Battle Drones, an RTS with audio-based multiplayer sync that became fun after he asked Claude to "make it a LOT more fun." A useful read if you are judging "AI-native games" pitches. ([simonwillison.net](https://simonwillison.net/2026/Oct/28/))
5. **Axiom, "Formalizing the Enormous Theorem"** (Oct 27, technical writeup plus repo, institutional). They produced a complete, sorry-free Lean 4 formalization of the Classification of Finite Simple Groups: about 43.1M lines in 24 days, using only the standard axioms. Along the way it found a problem in a published Unbalanced Group Theorem argument and supplied an alternative proof. Read it next to the ETH Lean caveats: machine-checked proofs at this scale are now routine, but checking the theorem statements still needs humans. HN 226. ([Axiom](https://axiommath.ai/research/the-enormous-theorem-formalized/) · [GitHub](https://github.com/AxiomMath/CFSG/blob/main/README.md))
