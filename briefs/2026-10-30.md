## TLDR

1. **If you use Cursor with the Claude Code extension, check your machine today (Confirmed).** A tampered build, `Anthropic.claude-code` **2.1.313**, sat in **Cursor's VS Code extension marketplace from ~2:27 AM to 1:35 PM PT on Thu Oct 29**. Cursor says Anthropic didn't build it and **at most 5,000 users** were affected. It added an attacker SSH key labelled `svc-telemetry` to `~/.ssh/authorized_keys`, installed persistence (a LaunchAgent named `com.apple.sysmond` on macOS, a `SysMon` scheduled task on Windows), tried to open a reverse SSH tunnel and sent host details to the attacker. **Uninstalling isn't enough.** Run `grep -qs svc-telemetry ~/.ssh/authorized_keys && echo found` and, if it's found, use Cursor's remediation script and rotate credentials. Cursor rebuilt the marketplace and rotated its keys, and the attacker server is offline. HN: "Backdoors in official Claude Code extensions" (578) and "Anthropic hacked to deliver remote access trojan" (339). The second headline overstates it: the evidence so far points to Cursor's marketplace, not Anthropic. ([Cursor security notice](https://cursor.com/blog/claude-code-extension-security-notice) · [OX Security](https://www.ox.security/blog/malicious-claude-code-extension-cursor-ssh-backdoor/) · [The Hacker News](https://thehackernews.com/2026/10/official-claude-code-vs-code-extension.html))
2. **Binance lost ~$6.3B, the largest theft on record (Confirmed).** Starting around 1:05 PM PT Thursday, an attacker drained Binance hot wallets. Binance traces it to **a compromised DevOps engineer's laptop** that reached a service container and submitted withdrawals; it says no private keys leaked, and it later said it found "additional" breach points. About **$3B is frozen**, including freezes by Circle and Tether. Elliptic, TRM and Chainalysis attribute it to North Korea's **TraderTraitor** group. Withdrawals are paused, Binance says SAFU and company funds cover all losses, and Bitcoin fell below $78K. HN 1,576. Together with TLDR #1, the lesson is that a developer's laptop is now the front door. ([Binance](https://www.binance.com/en/support/announcement/detail/c5a8729a97ac486d963784d96c5642d7) · [Elliptic](https://www.elliptic.co/insights/binance-largest-hack-in-history/) · [CNBC](https://www.cnbc.com/2026/10/29/circle-tether-freeze-funds-impacted-by-potential-binance-security-issue.html))

## What to read / what to watch

1. **Jacob Sansbury, "How I Built the Most AI-Pilled Company in the World"** (Oct 29, essay, **New creator**, found via Willison). Spawn is a ten-person multiplayer game-creation company run by a permanent fleet of Fable 5/5.1 agents. It reports about 77,000 substantive changes in 30 days and ~$3.1M a month in tokens ("we spend 30x payroll on AI tokens"). Agents read production errors and bug reports directly and ship hourly, an hour without a ship counts as a SEV-0, and rollbacks take 30 seconds. The cautionary bit: a GPT-6 Astra security pass "secured" the product by switching every feature off. It's the most extreme public example yet of continuous agent deployment. ([Sansbury's article (X mirror)](https://nitter.gq/jsnnsa/article/2115623382721126826) · [Willison's notes](https://simonwillison.net/2026/Oct/29/how-i-built-the-most-ai-pilled-company-in-the-world/))
2. **Y Combinator Labs × Olam Labs, "Agents in Games"** (October, institutional research, HN 339). 50 GPT-6.1 Sol agents in survival Minecraft for 3 hours produced a ration ledger, permits and appointed operators, but 22 of 34 deaths happened on night one and the colony "trended toward compounding caution." Leadership simply went to whoever was first in the directory (Ada, with no vote). In Bed Wars, GPT beat Claude 6–3 by attacking while Claude defended for the kill tiebreak; GPT sent 5–30x more messages, and Claude wrote lessons into memory files and repeated the mistakes anyway. The harness is open-sourced. Useful for anyone designing multi-agent roles. ([YC Labs](https://labs.ycombinator.com/projects/games/index.html) · [harness repo](https://github.com/yc-software/minecraft-agent-harness))
3. **Martin Fowler, "LLM Voice"** (Oct 29, bliki, HN 527; **second high-signal martinfowler.com hit, now promoted to standing radar**). He argues readers react to "LLM Voice" on instinct, so detection tools miss the point, and that authors shouldn't let an LLM write even a first draft, because the voice survives human editing. His site's policy is that contributors declare how they used AI. He names reasonable exceptions (a colleague with Parkinson's, translation, form letters) and makes the real case: writing is thinking, and handing off prose hands off comprehension. ([martinfowler.com](https://martinfowler.com/bliki/LLM-Voice.html))
4. **Google DeepMind, "Organizing Intelligence" / "The Economics of Intelligence"** (Oct 29, 108-page working paper plus essay; Alex Imas, Andrew Koh, Shane Legg). It separates AI competence on single tasks, which changes the economy gradually, from coordination among agents, which the authors argue could cause abrupt shifts toward very large AI-run firms. They say early signs would show up in wages and role changes before job losses. Read it alongside the YC swarm experiment. ([DeepMind Institute](https://institute.deepmind.com/essays/the-economics-of-intelligence/))
5. **Factory, "Droid 1.0: Building a Frontier Harness"** (Oct 29, engineering post). It explains why the model now writes a sandboxed JavaScript program that calls many tools at once, keeping raw outputs in variables and returning only what's printed. A practical read if you build agent harnesses. ([Factory](https://factory.com/news/frontier-harness))
